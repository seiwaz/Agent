# Analytics V5

Runtime gates are only those explicitly defined in V5. Other features remain analytics unless separately promoted in a future spec.

Track:
- same-color count
- strong bars/body/wicks
- ATR cohorts
- PullbackDepth
- P-Gap survival
- M15
- round levels
- AB=CD projection
- Leg1/Leg2 ratios
- hour/session
- MFE/MAE
- E1 revision count

Required comparisons:
- Base candidates vs Context-pass
- Context-rejected counterfactual
- Exhaustion-rejected counterfactual
- E1-only vs E1+E2
- expectancy, PF, average R, drawdown, fees, trade count

No automatic parameter selection.
